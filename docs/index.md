# AVDASI 2

The AVDASI 2[^1] design, build and test unit is a keystone of the Aerospace MEng and BEng programmes at the University of Bristol.

This site holds technical resources for the unit, including documentation and code samples, which should be used alongside the wider unit documentation. It's aimed at students on the unit, but we're publishing it openly in case it's useful to others. If you use it, [we'd love to hear about it](mailto:AVDASI2@bristol.ac.uk).

As of the current teaching year, this site is largely for the [Avionics](avionics/index.md) subdiscipline. See the unit SharePoint for session schedules and other resources.
