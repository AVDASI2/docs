# private/

Internal material that must not be published: draft requirements specifications,
content reviews, assessment briefs and rubrics, student work, and anything
licensed that can't be redistributed.

`reviews/` holds the content reviews. They were tracked in git until 20 Sep
2026; the versions up to then remain in the repository's history, but changes
from now on are not version-controlled, so keep the OneDrive backup in mind.

Everything here except this README is ignored by git, so nothing in it reaches
the site or GitHub. Drop files straight in.

Drafts of the requirements specification live here, or in the teaching share
under `Avionics and Mechanisms - SB/slides - avionics/for Claude/`. Either works;
the share is easier if the document is being edited by several people.
